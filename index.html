What this comparison means

RMSD depends on the chosen atoms, region and fitting method. The fit uses every matched Cα in the selected window without rejecting outliers. A small local value does not establish normal function; whole-model differences include low-confidence regions.

Rules & original weights

Preset weights follow the main predict_functional_effect function in the supplied code. The separate custom-property function used different weights; this version uses one consistent preset engine.

Pressure adds floor(input × 0.25); contact adds 25; clamp at 100. WT uses a zero chemical baseline. The three output labels are teaching channels, not validated measurements of structure, DNA or network disruption.
